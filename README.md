# 🐦 Twitter UI Clone

A clean and responsive **Twitter/X UI Clone** built using **Tailwind CSS**.

## 🔗 Live Demo

👉 https://twitter-ui-gvog.vercel.app/

## ✨ Features

* 🐦 Twitter/X inspired UI
* 🏠 Home feed interface
* 🔍 Search interface
* 👤 Profile interface
* 💬 Tweet and reply UI
* ❤️ Like and interaction UI
* 📱 Responsive design
* 🎨 Modern and clean layout

## 🛠️ Tech Stack

* **HTML**
* **Tailwind CSS**

## 📌 About

This project is a **Twitter/X UI clone** created using Tailwind CSS.

The project focuses on recreating the visual design and layout of Twitter/X with a responsive and modern user interface.

> **Note:** This is a UI-only project. No backend, database, authentication, or real-time functionality is included.

## 🎯 Purpose

This project was created for learning and practicing:

* Tailwind CSS
* Responsive web design
* UI/UX design
* Modern CSS layouts
* Frontend development
